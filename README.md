# JavaScript Practice Programs

This repository contains beginner-friendly JavaScript programs created while learning web development.

## Topics Covered

- Operators
- Assignment Operators
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Template Literals
- Type Conversion (Coercion)
- Conditional Statements
  - If Else
  - Switch Case
  - Ternary Operator

## Programs

### Grade Checker
Uses switch statements to display feedback based on grades.

### If Else Programs
Basic decision-making programs using if-else conditions.

### Ternary Programs
Programs using JavaScript ternary operators.
